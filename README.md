# Causal Inference & Large-Scale Experimentation Portfolio Project

Work in progress.

## Scope
A staggered, non-randomly-selected city-level product rollout, with a nested
randomised A/B test inside treated cities, and geospatial spillover between
neighbouring cities. Built to demonstrate causal inference and large-scale
experimentation skills: confounding control, treatment effect estimation,
A/B test design and analysis (power, guardrails, variance reduction),
interference/SUTVA issues, and multiple testing at scale.

## Status
Project restarted from scratch (4 Sep 2026) - data simulation not yet done.
