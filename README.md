# Causal Inference & Large-Scale Experimentation: Geo-Rollout Analysis

A portfolio project demonstrating causal inference and large-scale A/B testing skills on a simulated marketplace dataset, built to reflect the kind of experimentation problem a Senior Data Scientist would work on at a two-sided online platform.

## The Scenario

A company runs a **geo-targeted ad campaign**, rolled out to a subset of cities in a staggered but **non-random** order — cities with higher growth potential are prioritised for business reasons, which is exactly what makes a naive before/after comparison misleading.

Inside the treated cities, there's also a **properly randomised A/B test** on individual users — a clean experiment nested inside a messy, real-world rollout.

Because ad targeting isn't perfectly precise, some campaign exposure **leaks into neighbouring cities** — a deliberate violation of the standard assumption that one unit's outcome doesn't depend on another's treatment status (SUTVA), used here to demonstrate spillover/interference-aware analysis.

The project's core question: **can standard and advanced causal inference methods recover the true effect of the campaign, despite the selection bias, and despite the spillover?**

## Skills Demonstrated

- Causal inference on observational data: stratification, propensity score matching
- Large-scale A/B testing: power analysis, minimum detectable effect, confidence intervals
- Variance reduction with CUPED
- Interference/SUTVA-aware analysis of spillover effects
- Multiple-testing correction at scale (false discovery rate)
- KPI definition and guardrail-metric framing
- Turning a technical analysis into a business-facing recommendation

## Reproducing This Project

1. Clone the repo and `cd` into it.
2. Install dependencies: `pandas`, `numpy`, `scipy`, `statsmodels`, `scikit-learn`, `matplotlib`, `jupyter`.
3. Run the notebooks in `notebooks/` in numbered order — each one is self-contained and documents its own steps.
